# Projects

## IoT Smart Security Monitoring System

One of the projects I have been working on is an IoT-based security monitoring system using an ESP32-CAM.

The idea is simple: detect activity, capture an image, record what happened, and alert the user.

The planned system combines:

* ESP32-CAM
* HC-SR04
* SIM800L
* Buzzer
* LED
* PHP
* MySQL
* Web dashboard

I chose this project because it brings together several areas I have been learning: hardware, programming, databases, networking, and security.

It has also helped me understand that building a complete system involves more than writing code. The different parts have to communicate correctly and work together.

## Enterprise Network Design and Security

I built an enterprise network simulation using Cisco Packet Tracer to practice how different parts of a larger network communicate.

The project included:

* VLANs
* Inter-VLAN Routing
* OSPF
* RIP
* EIGRP
* Route Redistribution
* ACLs
* Network security controls

I spent a lot of time troubleshooting configurations and trying to understand why traffic was or was not reaching its destination. This was one of the projects that made networking much more practical for me.

## Python Learning Master

Python Learning Master is a software project idea I came up with while learning Python.

The idea is to make learning Python more interactive for beginners instead of only reading lessons and writing code separately.

A learner would first learn a topic and then practice it through exercises and coding challenges. The platform would use different levels so that learners can gradually move from basic concepts to more difficult problems.

I want to continue developing this idea as my software engineering skills improve.
